# Symplifica - Dashboard de Empleados y Beneficios

Prueba técnica Fullstack Junior para Symplifica: dashboard que unifica empleados, beneficios y
geolocalización (OpenStreetMap Nominatim).

## Estado del proyecto

En construcción. Esta sección se irá completando a medida que avance el desarrollo.

## Arquitectura

- **Backend**: Ruby on Rails (API-only) — `backend/`
- **Frontend**: Vue 3 + Vite — `frontend/`
- **Base de datos**: PostgreSQL
- **API externa**: OpenStreetMap Nominatim (geocodificación por ciudad)

## Requisitos previos

- Ruby 3.3.5, Rails 7.2
- Node 22+
- PostgreSQL 16
